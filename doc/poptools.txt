INTRODUCTION                                    *poptools-introduction*

Poptools aims to scale your productivity by conveniently using popups for a
multitude of tasks, from finding files and directories, to setting your
favorite colorscheme.

Once a list of results is slammed into a popup menu, you can filter it in a
fuzzy or in an exact way.

Poptools is more essential compared to similar plugins, but differently
from them, external programs are called _synchronously_, although things may
change in the future. :)

Nevertheless, I personally like the interface and how it displays all the
results at once. Additionally, I find the opportunity of saving the last
search very handy. The configuration is also fairly straightforward.

COMMANDS                                          *poptools-commands*

It follows the list of available commads: >

    :PoptoolsFindFile
    :PoptoolsFindFileInPath # Takes into account the setting of :h 'path'.
    :PoptoolsFindDir # Search from the current directory downwards
    :PoptoolsBuffers
    :PoptoolsRecentFiles
    :PoptoolsCmdHistory
    # When something goes wrong, you can clear all the Poptools popups
    :PoptoolsKill
    # The displayed colors depends on the value of :h 'background'
    :PoptoolsColorscheme
    :PoptoolsGrepInBuffer # Find pattern in the current buffer
    :PoptoolsGrep # External grep. Grep command is displayed.
     # Vimgrep, show results in the quickfix-list instead of a popup.
    :PoptoolsVimgrep
    :PoptoolsLastSearch # Show the last search results
<

GREP AND VIMGREP                          *poptools-grep*  *poptools-vimgrep*

`PopupToolsVimGrep` uses |vimgrep| whereas `PopupToolsGrep` uses |grep|.
However, the user interface is the same.
The results appear both in the |quickfix-list| and in the popup window.

By default, |grepprg| is set,as it follows:

>
  # Windows
  &grepprg =
    'powershell -NoProfile -ExecutionPolicy Bypass -Command '
      .. '"& {Set-Location -LiteralPath ''' .. search_dir .. '''; findstr /C:'''
      .. what .. ''' /N /S ''' .. items .. '''}"'

  # *nix
  &grepprg = 'grep -nrH --include="{items}" "{what}" {search_dir}'
<

where the values of `{what}`,`{files}` and `{search_dir}` are replaced by
user input values.

You can also configure your own |grepprg| command through the keys
`grep_cmd_win` and `grep_cmd_nix` of the |g:poptools_config| dictionary and
you can use the placeholders `{search_dir}, {items}` and `{what}`.

The grep command sent to the shell can be retrieved through |:messages|.

TIP: Once you have performed a search, all the results can be accessed at any
time through `:PopupToolsLastSearch` without the need of performing a new
search.

CONFIGURATION                    *poptools-configuration* *g:poptools_config*

The plug configuration is done through `g:poptools_config` dictionary.
Be sure to create the empty dictionary `g:poptools_config = {}` before
filling it with he various keys.

      Available keys:
        "preview_file"    Set to `true` if you want a preview window when
                          searching for files.
                          Default `false`.
"preview_file_in_path"    Set to `true` if you want a preview window when
                          searching for files in path.
                          Default `false`.
"preview_recent_files"    Set to `true` if you want a preview window when
                          searching for recently opened files.
                          Default `false`.
     "preview_buffers"    Set to `true` if you want a preview window when
                          searching for buffers.
                          Default `false`.
       "preview_grep"     Set to `true` if you want a preview window when
                          using poptools grep functions.
                          Default `false`.
    "preview_vimgrep"     Set to `true` if you want a preview window when
                          using poptools vimgrep functions.
                          Default `false`.
       "fuzzy_search"     Set to `true` if you want a fuzzy filtering of the
                          results, or to `false` if you want to filter based
                          on exact match. Default `true`.
       "preview_syntax"   Set to `true` if you want syntax highlighting in the
                          preview window. Note that syntax highlighting may
                          slow down the user-experience. Default `true`.
       "grep_cmd_win"     Value of |grepprg| for Windows.
                          Default:
      >
              'powershell -NoProfile -ExecutionPolicy Bypass -Command '
                .. '"& { findstr /C:''' .. what .. ''' /N /S '''
                .. fnamemodify($'{search_dir}\{items}', ':p') .. ''' }"'
<

        "grep_cmd_nix"     Value of |grepprg| for *nix systems.
                          Default:
      >
               grep -nrH --include="{items}" "{what}" {search_dir}
<
If you define your own |grepprg|, then the elements in the quickfix shall
contain the buffer number, the line number and the text. You can verify it by
running `:echo getqflist()`. The returned dictionaries must have the keys
`bufnr`, `lnum` and `text`. If that is not the case, then you need to set
|grepformat| adequately. See |grepformat| for more info.
